The request lifecycle — URL to UI

Trace a visible result backward through the component, hook, service, and browser URL to find which layer owns a bug.

The complete flow

/coin/bitcoin
  → Route path="/coin/:id"
  → useParams() gives id = "bitcoin"
  → useMarketChart(id, currency, days)
  → queryKey identifies the cached request
  → fetchMarketChart builds the endpoint
  → request<MarketChart> fetches and parses JSON
  → chartQuery becomes loading, error, or success
  → CoinPage renders the matching UI

Inputs and owners

idURL via useParams
currencyshared Zustand settings store
dayslocal useState
endpointCoinGecko service
loading/error/dataTanStack Query
visible resultReact component

Query-key rule

queryKey: ['marketChart', id, currency, days]

Every value used by queryFn that can change belongs in the key. A different key means different cached data.

Render all request states

query.isLoading && <Loading />
query.isError && <Error onRetry={() => query.refetch()} />
query.data && <Success data={query.data} />

Where to investigate

  • Navigation or parameter problem → route and link.
  • Cache or refetch problem → hook and query key.
  • HTTP or endpoint problem → service.
  • Display or interaction problem → page and child components.
