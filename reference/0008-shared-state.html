Shared state with Zustand

Use a store when distant components need one shared source of truth. Keep one-component state local with useState.

Store shape

interface SettingsState {
  currency: FiatCode                         // state
  setCurrency: (currency: FiatCode) => void // action
}

Create and persist

export const useSettings = create<SettingsState>()(
  persist(
    (set) => ({
      currency: 'usd',
      setCurrency: (currency) => set({ currency }),
    }),
    { name: 'crypto-settings' },
  ),
)

set updates state and notifies subscribers. persist saves and restores the store using the configured storage key.

Select what a component needs

const currency = useSettings((state) => state.currency)
const setCurrency = useSettings((state) => state.setCurrency)

A selector returns the slice to subscribe to. Prefer narrow selectors over taking the whole store.

Validate values at the boundary

function handleCurrencyChange(value: string) {
  if (isFiatCode(value)) setCurrency(value)
}

DOM inputs return strings. A type guard validates external input and narrows it before the value enters typed shared state.

Currency update flow

select change
  → type guard
  → store action
  → state update + persistence
  → subscriber re-render
  → changed query key
  → new API data
  → updated prices
