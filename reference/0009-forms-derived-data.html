Forms and derived data

Keep editable drafts as strings, convert and validate at submission, and calculate values that can be derived from existing state.

Controlled input

const [amount, setAmount] = useState('')

<input
  value={amount}
  onChange={(event) => setAmount(event.target.value)}
/>

value reads from state. onChange writes to state. Browser input values are strings.

Safe submit sequence

draft strings
  → Number(...)
  → validate
  → typed store action
  → reset drafts
function handleSubmit(event: FormEvent) {
  event.preventDefault()
  const amountNum = Number(amount)
  if (!Number.isFinite(amountNum) || amountNum <= 0) return
  // use amountNum safely
}

Memoized calculation

const rows = useMemo(
  () => calculateRows(positions, pricesUsd),
  [positions, pricesUsd],
)

The dependency array lists every outside value used by the calculation. useMemo caches a calculation; it is not persistent state.

Useful rules

  • Do not trust a value merely because the input has type="number".
  • Convert once at the boundary, then work with numbers.
  • Validate before updating shared state.
  • Do not store a value you can cheaply derive from existing sources of truth.
  • Use useMemo for useful optimization, not for correctness.
