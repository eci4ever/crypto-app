Data fetching — reaching outside the component

Rendering is pure. Fetching is a side effect — an async trip to CoinGecko. This repo handles it with TanStack Query (useQuery), wrapped in small hooks.

The parts of a useQuery call

export function useMarket(currency: string) {
  return useQuery({
    queryKey: ['market', currency],   // cache identity — same key, same result
    queryFn: () => fetchMarket(currency), // the async function that fetches
    refetchInterval: 60_000,          // auto-refetch every 60s
    staleTime: 30_000,                // treat data as fresh for 30s
  })
}
  • queryKey — a unique label. ['market', 'usd'] and ['market', 'myr'] are two separate caches.
  • queryFn — must be async; returns the data.
  • refetchInterval — background polling, in milliseconds.
  • staleTime — how long the cached data is "good enough" before refetching.

What the hook hands back

const { data, isLoading, isError, refetch, isFetching } = useMarket(currency)
datathe fetched value (typed!)
isLoadingtrue on first load, no data yet
isErrortrue if queryFn threw
refetcha function to force a fresh fetch
isFetchingtrue during any fetch (incl. background)

Types come from queryFn's return type — so data is a CoinMarket[], and misusing it fails type-checking.

Underneath: fetch + Promise

async function fetchMarket(currency: string): Promise<CoinMarket[]> {
  const res = await fetch(url)       // network call, returns a Response
  if (!res.ok) throw new Error(...)  // errors are thrown, not ignored
  return (await res.json()) as CoinMarket[]  // JSON → typed object
}

Three async keywords, all you'll need for a while:

  • async — marks the function as returning a Promise.
  • await — pauses until a Promise settles, then gives you the value.
  • as CoinMarket[] — a type assertion: "I promise this JSON has that shape." (Used only at the edge of the app, where data enters.)

The flow, end to end

ListPage calls useMarket(currency) → Query runs fetchMarket → fetch talks to CoinGecko → JSON → typed data → rendered by CoinTable.
