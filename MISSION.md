# Mission: Frontend Development with TypeScript (maintain crypto-app)

## Why

The user has a working cryptocurrency price viewer (this repo, `crypto-app`) built in React 19 + TypeScript + Vite, but can't read most of its `src/` files. They want to go from "a little HTML/CSS/JS" to confidently **writing frontend code in TypeScript** and **maintaining and extending this repo themselves** — rather than relying on an agent for every change.

## Success looks like

- Read any file in `src/` and explain what it does and why
- Make a real feature change to crypto-app (new page, new component, new API call) and ship it via a pull request
- Fix a broken build or failing test by reading the error message
- Write TypeScript types for a new feature without asking
- Refactor a component safely and know the tests catch regressions

## Constraints

- The primary teaching ground is this exact repo (React 19, Vite, TanStack Query, Zustand, Tailwind, wouter)
- User is Malay-native but prefers explanations in English; short Malay glosses welcome
- One small lesson per session, in the user's zone of proximal development
- No backend / server work

## Out of scope

- Backend development and Node.js servers
- Advanced TypeScript type gymnastics (mapped / conditional / template-literal types) until the fundamentals are genuinely solid
- Deep animation, design, or styling craft
